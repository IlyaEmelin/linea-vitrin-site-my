# landing-vitrin-site

Учебный фронтенд-проект для гайда «Дело о картине без происхождения».
Закрытая галерея принимает первичные обращения по делу о картине без происхождения. Посетитель оставляет только контактное лицо, телефон для связи и ожидание по вознаграждению за наводку.


## Что собираем

Дело о картине без происхождения с секциями:

- Витрина дела;
- Основания для контакта;
- Первичная форма запроса;

Витрина дела:

- секция __объясняет суть__: закрытая галерея принимает __первичные обращения__ по делу о картине __без происхождения__;
- она __не должна выглядеть как расследование вокруг дорогой картины__ (иначе — внимание прессы);
- её задача — довести посетителя до «Первичного запроса», а не рассказать историю владения.

Первичная форма запроса должна содержать поля ввода:

- поля «Контактное лицо», 
- «Телефон для связи» 
- «Вознаграждение за наводку»;
